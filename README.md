NexaDesk

NexaDesk is a web-based help desk ticket management system built with Java and Spring Boot.

Features

• Create support tickets.
• Add ticket titles, descriptions, and priorities.
• Store ticket data in a MySQL database.
• Manage ticket status.

Technologies Used

• Java
• Spring Boot
• Spring Data JPA
• MySQL
• HTML, CSS, and JavaScript
• Thymeleaf
• Maven

Project Status

Currently under development as a practical project to improve software development skills.
